Talk 8 · Google DeepMind

Carolina Parada / Google DeepMind: Language to Motion

The talk explains how Gemini Robotics turns multimodal foundation models into physical agents by adding action as a model output, then layering planning, tools, memory, safety evaluation, and whole-body control around it.

YouTube source · Talk page

Core Problem

Traditional robots are bespoke systems: they assume fixed environments, known objects, and hand-programmed task sequences. General-purpose robotics needs systems that can understand natural language, perceive cluttered scenes, reason over multi-step goals, and produce safe robot trajectories across different embodiments.

First-Principles Model

A useful robot needs at least two levels of intelligence. The high-level agent interprets the human goal, gathers context, uses tools, remembers the scene, and decomposes the task. The low-level action model turns a grounded instruction plus perception and proprioception into control targets, while a controller keeps the body stable.

Key Claims

  • General-purpose robots must operate across environments, verticals, object types, and embodiments rather than being programmed one task at a time.
  • Gemini Robotics adds actions as a modality to a multimodal model, so the system can output robot trajectories instead of only text, code, or images.
  • Agentic robotics is needed because real tasks are multi-step: the robot must reason, use tools such as search or code execution, and call action models as needed.
  • Agentic vision lets a model take intermediate perception steps such as zooming, pointing, and calculation before reporting an instrument reading or safety-relevant state.
  • Action models can generate text and action tokens together, creating a form of embodied thinking for multi-step manipulation.
  • Learning across embodiments matters: the same weights can transfer skills from one robot platform to another when one embodiment has less data.

Worked Example

A human asks an Aloha robot: "Can you sort these fruits into color-matching plates?" Gemini Robotics generates a response: "Sure, I can certainly help you do that. Put the green fruit into the green plate." The model generates text and action tokens together. It perceives the environment, recognizes different fruit colors and different plate colors, thinks step by step, then executes the multi-step task. It picks up the banana and places it on the yellow plate. The model is generating text and action tokens in parallel, enabling the robot to reason about what it's doing as it does it. In a second example, a human presents an unseen basketball hoop toy and says "slam dunk the basketball." The robot had never seen this object or task before. It took a quarter of a second to decide: put the small ball into the basket. This is the kind of generalization the speaker cares about.

On the instrument reading front, Boston Dynamics' Spot robot needs to read gauges in industrial facilities. With agentic vision, the model decides to zoom into the gauge to get a better reading, uses pointing and code execution to calculate exact interval values, and then calls a tool to determine whether the gauge reading is within normal range. The model is 93% accurate on real, noisy, small images from field examples. The same Gemini Robotics ER weights work across three different robots: the Aloha arm, the Apollo humanoid, and others. When training data is scarce for Apollo, the model learns from Aloha's training set; the shared weights transfer the learned skills.

One Level Deeper

The architecture splits into two levels. High-level reasoning layer (Gemini Robotics ER: embodied reasoning) understands the scene, the human's natural language, reasons about the sequence of steps needed, and can use tools like web search or code execution. Low-level action model (VLA: vision-language-action) takes visual observations, the grounded instruction, proprioception, and previous actions, and outputs direct robot control targets—either end-effector positions or full joint angles. Below that sits a whole-body controller, an RL policy that tracks the VLA output and ensures the robot stays stable. The key innovation is that the model generates text and action tokens together, creating embodied thinking. Unlike VLMs that only produce language or code, Gemini Robotics can output robot trajectories as a native modality. Agentic vision lets perception be iterative: the model can zoom, point, reason, execute intermediate code, and verify before committing to an action. This is especially useful when the task requires reading an uncertain measurement or handling clutter—the robot takes intermediate steps to reduce uncertainty before acting.

Failure Boundary

The speaker notes this is a frontier lab architecture, not a simple recipe. The hard parts are not just model calls; they include action data collection (still relying on teleoperation with "goggles and gloves"), embodiment transfer learning, safety evaluation, low-level control stability, and deployment partnerships. The speaker is bullish about learning from video "the way humans do," but the current system still relies on robots being teleop-trained and world models for safety evaluation. If the world model becomes inaccurate, safety evaluation in simulation breaks down—simulated failures may not match real ones, or real failures might not be caught. The VLA must output control targets fast enough for closed-loop control, which limits inference time and model complexity. If a task requires knowledge outside Gemini's training (e.g., a new material type that behaves unexpectedly), the model may fail or hallucinate a plausible-looking action that produces an unsafe result. Cross-embodiment learning works when embodiments are similar, but transferring from a small arm to a humanoid may degrade performance if the dynamics are too different. The ER layer can fail to decompose a task correctly if the human instruction is ambiguous or if the scene contains objects that mislead the reasoning chain.

Important Terms

Vision-Language-Action Model

A model that accepts visual observations and language instructions and directly outputs robot action targets or trajectories.

Gemini Robotics ER

The high-level embodied reasoning layer described in the talk: it understands the scene, uses tools, plans steps, and orchestrates action models.

Agentic Vision

Perception as a multi-step process, where the model can zoom, point, calculate, call tools, and verify before giving an answer.

Cross-Embodiment Learning

Reusing learned skills or model weights across robot bodies such as Aloha, Apollo, quadrupeds, and arms.

World-Model Safety Evaluation

Using generated or simulated robot observations to evaluate policies in risky situations that should not be tried directly in the real world.

Connection To Stanford Agent Learning

  • This extends the Stanford agent pattern from text tools into embodied tools: reason, call tools, act, observe, and continue.
  • The ER-plus-VLA split resembles planner/executor architectures in agent systems.
  • The simulation and world-model section connects to self-improvement because safer virtual evaluation creates more feedback for policy refinement.

Practical Caution

The talk presents a frontier lab architecture, not a simple recipe that any team can reproduce. The hard parts are not just model calls; they include action data, embodiment transfer, safety evaluation, low-level control, and deployment partnerships.

Takeaway

DeepMind's framing is that robotics needs a layered foundation-model system: embodied reasoning for goals and tools, action models for trajectories, controllers for stability, and simulation/world models for safety and scaling.
